# Series: ___ Got Admin For One Round

Format: one character gets admin commands for a single round. The ADMIN countdown is on screen the whole time; each
command is typed in chat and gets its own visual payoff every 4-5 s; a twist at the end; a cliffhanger into the next part
(the next character gets admin); then the call to action.

Cast: Leo (orange hoodie, cheeky, main troublemaker), Max (teal, Leo's rival), Mia (purple, the sensible one, deadpan),
the noob (AFK, never moves; from The AFK Millionaire).

Running gags: Leo always comes back; whoever has admin is undone by their own command or the clock; Mia judges everyone.
