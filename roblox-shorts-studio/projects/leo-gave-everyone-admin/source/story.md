# Leo Gave Everyone Admin (Part 3)

Series: "___ Got Admin For One Round" (`ideas/series/admin-for-one-round.md`). Part 2 ended with the crown dropping on
Leo; Part 3 picks up there. The whole cast plays a part: Leo starts it, Max fights back, Mia wins with brains (her
first admin), the noob is the twist. Roblox R6 pack, web route, George narration.

Why it's not Part 2 again: an admin WAR (everyone has admin, commands fly both ways) instead of one person working
through a list on one victim; all new commands (explode, invisible, giant, rocket, dance); a slow-burn gag running
under the chaos (Mia's ever-growing command in the chat box); the sensible character wins.

Rules carried over (analytics + Part 2 review):
- Frame 1: the crown on Leo, "LEO ADMIN 1:00", "1 ROUND = 1 MINUTE"; the first spoken line states it too.
- ADMIN countdown on screen throughout; typed chat commands; "PART 3" tag; a payoff every 2-4 s.
- Arms via web/lib/gestures.js; nothing passes through solid things; key action kept clear of the captions.

Beats:

2. Crowns drop on EVERY head: Max, Mia, and the AFK noob in the corner (he doesn't react; plant for the twist).
   Chat: "[Server]: Everyone is now an admin." Leo's face.

   Mia sips... no: Mia sits on the ice-free ground, deadpan, crown on. "MIA WINS".
