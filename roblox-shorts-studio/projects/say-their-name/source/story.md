# Say Their Name (standalone story, one part)

Mode: game rule with a downside, third person (references/story.md). The analytics review of 2026-10-05 found
Admin-style rivalry premises and simple game rules (Every Jump Makes You Bigger) hold viewers best, so this is a
four-player rivalry built on one game rule. Script: `../script.txt` (155 words with the CTA; expect about 61-62 s of
speech, a 62-64 s video: inside the 61-65 s rule). Cast: Leo, Max, Mia, the Noob. Route: web (three.js), obby tower
from the pack (`obby_block_*`, `truss`, `lava_strip`, `finish_pad`, `coin_pile`).

## The rule (one, kept consistent)
Say a player's name (the name on their name tag) out loud and they instantly teleport next to you, wherever you are.
First to the top of the tower wins a million coins. Everything that happens comes from the rule:
- summoning drags the leader back down, so nobody can win (the ping-pong);
- a new name tag beats a shout but not someone who can read (Steve);
- you appear *next to* the caller, even if that's thin air over lava (Mia's trap);
- a name only works once it's finished, so a long enough username buys time (the Noob). The last "Pop" uses the same
  rule one more time: finishing his name summons the winner, coins and all.
